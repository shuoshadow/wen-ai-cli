# MCP 快速开始

## 🚀 快速配置（5分钟上手）

### Step 1: 安装 Python MCP SDK

```bash
pip install mcp
```

### Step 2: 配置 MCP Server

编辑配置文件 `~/.wenai/conf.json`：

```json
{
  "defaultLang": "zh-CN",
  "openai": {
    "apiKey": "your-api-key",
    "baseURL": "https://api.openai.com/v1",
    "model": "gpt-4"
  },
  "mcp": {
    "enabled": true,
    "servers": [
      {
        "name": "local-system",
        "command": "python3",
        "args": ["/Users/sunshuo/data/hpk/code/wen-ai-cli/mcp/servers/local_system_server.py"],
        "env": {},
        "enabled": true,
        "autoStart": true
      }
    ]
  },
  "answerConfig": {
    "enableExplain": true,
    "enableExtendParams": true,
    "enablePlatformPerception": true,
    "enableWorkUserAndDir": true
  }
}
```

### Step 3: 测试使用

```bash
# 重新编译
cd /Users/sunshuo/data/hpk/code/wen-ai-cli
go build -o wen .

# 测试查询服务状态
./wen "nginx 服务运行正常吗？"

# 测试查询端口
./wen "查看 8080 端口被什么占用"

# 测试查询进程
./wen "有哪些 docker 进程在运行"
```

## 💡 工作流程

```
1. 用户提问："nginx 服务状态怎么样？"
   ↓
2. AI 识别需要查询实时数据
   ↓
3. 生成工具调用：
   <tool_call>
   {
     "name": "check_service_status",
     "arguments": {"service_name": "nginx"}
   }
   </tool_call>
   ↓
4. MCP Manager 调用本地系统 Server
   ↓
5. 返回真实数据：
   ● Active: active (running)
   ● Main PID: 1234
   ↓
6. AI 基于真实数据生成答案和命令
```

## 🎯 可用工具

项目已内置本地系统工具 Server，提供以下功能：

| 工具名称 | 功能 | 参数 |
|---------|------|------|
| `check_service_status` | 查询系统服务状态 | service_name: 服务名 |
| `check_process` | 查询进程信息 | process_name: 进程名 |
| `check_port` | 查询端口占用 | port: 端口号 |
| `disk_usage` | 查询磁盘使用 | path: 路径（可选） |
